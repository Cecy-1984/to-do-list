# 📝 To-Do List

Aplicación web de lista de tareas desarrollada como proyecto de práctica de desarrollo web.

## 🚀 Demo

[Ver aplicación](https://cecy-1984.github.io/todo-list/)

## 📌 Descripción

Esta aplicación permite crear, completar y eliminar tareas de forma sencilla.

El proyecto fue desarrollado para practicar conceptos fundamentales de desarrollo web y JavaScript.

## ✨ Funcionalidades

- ➕ Agregar nuevas tareas
- ✅ Marcar tareas como completadas
- 🗑️ Eliminar tareas
- 🧹 Limpiar tareas completadas
- 🔢 Contador de tareas pendientes
- 📱 Diseño responsive

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- Git
- GitHub Pages
